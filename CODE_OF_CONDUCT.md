# Community code of conduct / 社区行为准则

We welcome people of different backgrounds, skill levels, languages and research traditions. Be respectful, discuss technical evidence rather than personal attributes, accept constructive disagreement, and recognize contributions accurately.

Unacceptable behavior includes harassment, threats, discriminatory remarks, unwanted sexual attention, doxxing, deliberately misleading claims, and sharing someone else's confidential information without consent.

Report conduct concerns to the maintainer through an appropriate private channel. If no private channel is known, request one without publicly disclosing sensitive details. The maintainer may remove harmful content, warn participants or restrict participation as appropriate; avoid retaliation against reporters. Apply these expectations to repository discussions and project-related interactions.

中文：尊重不同语言、背景与经验的贡献者；以证据讨论技术问题，不进行人身攻击、骚扰、歧视或泄露隐私。遇到问题请联系维护者并保护相关人员隐私。
