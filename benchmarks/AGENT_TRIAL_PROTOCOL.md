# Matched agent repair evaluation (not yet executed)

This is the end-to-end protocol separate from lexical retrieval. Use the official [SWE-bench evaluation harness](https://www.swebench.com/SWE-bench/guides/evaluation/) and a fixed dataset revision/instance list. Choose the full Verified test split or predeclare a hash-sampled subset before viewing any outcomes; never select by success. Do not provide gold patches, test patches, evaluation logs, or future issue solutions to the patch-generating agent. Use two isolated processes/worktrees per task and seed, identical model revision, scaffold, prompt other than the Skill intervention, generation settings, allowed tools/search policy, hardware/image, token/time/tool budgets, and repository base commit. Record actual token/time/tool usage. No model API or credential is required by this offline score importer; a real model execution environment is required to obtain results.

1. Write a protocol JSON with schema_version 1; dataset, dataset_revision, split, evaluator_commit, scaffold_commit, skill_commit, model, model_revision, environment, network_policy, generation_config, max_tokens, max_tool_calls, max_seconds, seeds, instances (each instance_id, repo, base_commit). Full SHA-1 for revisions; no secrets.
2. Freeze `python benchmarks/agent_trials.py --freeze protocol.json --output protocol-lock.json` before either arm. Preserve the lock independently.
3. Generate actual predictions in separate runs with/without the frozen Skill. Use distinct evaluator run IDs (the official harness caches by run and instance). Evaluate via the official harness using the frozen IDs and split. Do not copy gold patches as predictions.
4. For each arm, create an explicit artifact root, with manifest.json containing protocol_sha256, arm ("baseline"/"skill"), applied_skill_commit (null or exact frozen commit), run_ids mapping each seed string to a unique evaluator run ID. Under seed-<seed>/ put predictions.json (the actual official array of instance_id, model_patch, model_name_or_path), usage.json (mapping task IDs to tokens, tool_calls, seconds), reports/<instance_id>/report.json and patch.diff copied from the corresponding official evaluator run. For an absent report, omit it, not invent a result. An empty predictions array and usage object can document an attempted but blocked replicate. No links or unsafe paths.
5. `python benchmarks/agent_trials.py --lock protocol-lock.json --baseline /path/to/baseline --skill /path/to/skill --output trial-results.json`.

The scorer checks exact patch bytes, official per-instance resolved booleans, protocol digest, distinct run IDs, budgets and fixed task denominator. Missing submissions, empty patches, infrastructure/grade errors and missing/over-budget usage are not successes. It reports paired task-cluster bootstrap intervals (seeds are not independent tasks), all statuses and recorded costs. The artifacts are supplied by the operator; this is not an authentication or causal proof. Unit tests are synthetic and must never be reported as actual model evaluation. No actual same-model SWE-bench agent comparison has been performed in this repository at the time this protocol is introduced.
