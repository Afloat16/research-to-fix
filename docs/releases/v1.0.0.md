# Research to Fix v1.0.0

**First stable release — evidence-first multi-round research, measured alternatives, and reusable repairs.**

## Highlights

- Bounded research session ledger: proposals, plan-bound results, namespaced query IDs, distinct-query budget, gaps and targeted follow-up.
- Optional public metadata discovery across seven service families, balanced provider scheduling, bounded independent workers, and explicit access failure reporting. No mandatory dependencies, keys, crawler, full-text fetcher or autonomous agent runner.
- Source identity conflict and publication-warning review; explicit paper–code paired ranking, with BM25 retained as the compatible default.
- Prospective protocol and candidate design locks, supporting-source locators, revision/license review, exact hard thresholds, paired metrics and both median/all-pairs Pareto frontiers.
- Source-linked cross-domain/bilingual fixtures, numerical variance and exact-attention examples, deterministic regression gates, bilingual documentation and figures.
- Versioned skill archive and SHA-256 built directly from the tagged commit. Extract the `research-to-fix/` directory into a supported Agent Skills host; alternatively install from the repository with `npx skills add Afloat16/research-to-fix --skill research-to-fix`. Python helpers require 3.10+ and only standard library. Host installation/execution depends on the host.

[Offline CI measurements](https://github.com/Afloat16/research-to-fix/actions/runs/45355977079): simulated 40 ms request latency, six requests, five repetitions: 243.691 ms sequential and 83.175 ms three-worker median (2.93×), identical search records except timestamps. Five-seed exact-attention CPU Python comparison: full-matrix 634,920 B vs online 25,008 B peak traced allocation (96.06% less, output included, input excluded); all candidates passed 1e-10 accuracy gate and regression checks. Online median runtime 45.38 ms vs full-matrix 42.91 ms, so no speedup claim. Both design and protocol locks checked.

[Explicit public known-item probe](https://github.com/Afloat16/research-to-fix/actions/runs/45355435962): GitHub, Crossref and OpenAlex completed, 15 observations, 14 identities, matching target DOI and repository. arXiv unavailable; Semantic Scholar rate-limited; DBLP invalid response. One item is not representative of real search coverage; full sources still require review.

Raw printed reports are frozen in [v1-snapshot.json](https://github.com/Afloat16/research-to-fix/blob/v1.0.0/docs/figures/v1-snapshot.json). The linked release workflow runs the tests and quality gates again before publishing.

## Compatibility and limitations

Case schema v1, offline default behavior and legacy recall ranking remain. New research sessions and locks are optional. Old comparison files without locks remain supported; supplying a design digest requires its matching design lock. All supporting external evidence must be reviewed; unverified leads can be listed separately. Never treat a source link, score or hash as proof of correctness, license permission, chronology, or general solution success. Ordinary CI is offline. The development corpora are not blind held-out evaluations, and the CPU experiment is not a GPU kernel benchmark. End-to-end same-model agent repair efficacy has not been established.
