# Research to Fix v1.1.0 — external evaluation and precision retrieval

This release retains the evidence-first research, multi-round discovery, matched-experiment decision, and verification workflow of v1.0.0. It adds measured external retrieval evidence, optional Precision Field ranking and exact-parity performance improvements.

## Highlights

- Four frozen public holdout corpora: 84,892 documents and 1,864 positively judged queries, selected before final evaluation. Complete source manifests, all methods and paired intervals.
- Opt-in `precision_field` for recall, batch recall and evidence triage; compatibility-preserving default BM25. Exact/stem/phrase features and independent field normalization, fixed from the development bucket.
- Compared with preselected tuned SQLite, relative nDCG@10 improvements of 11.52% (Programmers), 11.49% (Stats), and 8.32% (NASA), with positive pointwise paired 95% intervals. SciFact inconclusive, v1 Contextual comparison inconclusive on all four.
- Actual BM25S 0.2.14 post-holdout diagnostic: NASA nDCG@10 0.4665 vs matched BM25S 0.4389; SciFact and absolute raw retrieval speed do not establish R2F superiority.
- Exact base-token and feature-sequence acceleration; optional NumPy score-only adapter (5.22× SciFact, 6.70× NASA prepared-token P50, exact scores and IDs for all 512 queries; Linux CPython 3.13 validation). Additional setup/memory, index build and full agent execution excluded.
- Matched-agent/SWE-bench result importer and protocol with frozen denominators, patch identity, budget checks and paired task intervals. No actual same-model repair-success experiment yet.
- Bilingual publication figures, complete JSON summaries, explicit failure and uncertainty accounting. Ordinary CI offline; no mandatory Python third-party dependencies for default usage.

The external results do not show universal superiority, dense-model superiority, or causal agent repair-rate improvement. No post-holdout retuning is counted as blind evidence. The installable Skill ZIP and SHA-256 are built from the tagged commit. Installation: `npx skills add Afloat16/research-to-fix --skill research-to-fix` or extract the versioned archive into a compatible host.
