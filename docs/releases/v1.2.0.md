# Research to Fix v1.2.0 — exact recall and evidence audits

A compatibility-preserving release for faster case reuse, deeper research coverage and more defensible comparisons. Default lexical scores and result semantics are unchanged; no mandatory runtime dependencies added.

## Measured improvements

- **2.85–4.83×** P50 on six generated warm-index workloads, **59.4–65.8%** lower sampled peak allocation, and **288/288** exact count, score, ID, order and explanation equality.
- **4.88×** P50 on all 804 real Mathematica queries (35.36 → 7.24 ms), with exact full-result parity. Prepared-token comparison against the previous explanation path, not end-to-end latency.
- **16,705 documents, 804 queries, eight methods:** predeclared external transfer includes actual BM25S 0.2.14 and rank-bm25 0.2.2. Precision Field nDCG@10 0.2366, +9.71% vs SQLite Unicode 4 and +5.87% vs rank-bm25 Matched; pointwise paired intervals positive. Contextual scores 0.2389, comparisons against it and BM25S inconclusive; BM25S queries are faster. All results and tradeoffs reported.
- Across five public corpora: 101,597 documents and 2,668 judged queries, evaluated separately.

## Engineering

- Exact threshold count, bounded Top-K, deferred explanations.
- Research stage coverage audit: unplanned, incomplete/mixed, completed-empty and completed-with-observations states; original-read counts and missing search status.
- Matched multi-arm agent evaluation importer: frozen intervention digests, fixed model/tasks/seeds/budgets, patch/run consistency, fixed denominators, task-level intervals and multiplicity-adjusted sign tests. Actual same-model agent trials have not been run.
- Two new bilingual, generated README dashboards, tested against committed measured JSON.
