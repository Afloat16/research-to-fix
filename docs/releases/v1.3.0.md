# Research to Fix v1.3.0 — Frozen execution and evidence consistency

## Measured results

- 21 controlled repair candidates across seven Python defects; 42 actual test subprocesses, 174 method outcomes and 21 consistent evidence bundles. Full frozen tests reject seven incomplete symptom-only candidates while accepting all seven designed fixes.
- Semantic audit detects all 13 named contradictions after resealing, whereas unpinned hash verification rejects none. Independently retained original manifests detect all 13 with either method. The coherent-edit control passes both unpinned checks; neither proves authenticity.
- 272 paired research status simulations: mean completed stages 4.76 → 5.36; source families 2.61 → 4.68; all-stage completion 20.6% → 37.9%. Counterevidence completion unchanged. No live search or repair-rate claims.

## Engineering

Trusted local stdlib unittest recorder with frozen before/after code and common tests, explicit execution approval, time/output bounds and preserved raw reports; semantic evidence and offline plan-binding audits; opt-in coverage-first planning with legacy CLI compatibility; reproducible bilingual evidence dashboard. No new mandatory runtime dependencies. The recorder is **not a sandbox**; execute only trusted files. Keep independent plan/manifest digests.
